# Widget Gigalink — instalar no Windows

## Passo 1 — Baixar o instalador
Acesse este link e baixe o arquivo `.exe` mais recente (algo como
`Widgets-Gigalink-Setup-0.2.0.exe`):

https://github.com/JoaoGigalink/widgets-gigalink-atualizacoes/releases/latest

## Passo 2 — Instalar
Dê um clique duplo no arquivo baixado. Não precisa clicar em nada além
disso — a instalação é automática (sem telas de confirmação).

## Passo 3 — Fazer login
O app abre sozinho depois de instalar. Na primeira abertura, ele pede
usuário e senha. Use os que você já tem. Se pedir pra trocar a senha, é
normal — só seguir o passo.

## Pronto
O widget vai aparecer no canto da tela, sempre visível. Ele abre sozinho
toda vez que você ligar o computador — não precisa abrir manualmente.

## Sobre atualizações futuras
Você não vai precisar baixar um instalador novo toda vez. O app confere
sozinho se saiu uma versão nova e avisa com uma bolinha amarela perto do
botão de atualizar (ícone de seta circular) no widget. Quando aparecer,
é só clicar nela e confirmar — ele reinicia sozinho já na versão nova.
