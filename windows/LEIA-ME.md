# Widget Gigalink — instalação (Windows)

## O que é
Um card flutuante na área de trabalho com os números da semana (faturamento,
ativações vs. churn, vendas por vendedor). Atualiza sozinho a cada 60s.

## Como instalar
1. Baixar o instalador mais recente na aba
   [Releases](https://github.com/JoaoGigalink/widgets-gigalink-atualizacoes/releases/latest)
   deste repositório (arquivo `Widgets-Gigalink-Setup-X.X.X.exe`).
2. Rodar o `.exe` baixado (clique duplo).
3. Na primeira abertura, o app pede login — usar seu usuário e senha.
4. Se a senha for temporária, o app vai pedir pra trocar antes de mostrar os
   widgets — normal, só seguir o passo.

## Depois de instalado, não precisa reinstalar de novo
A partir da versão 0.2.0, o app se **atualiza sozinho**: confere, baixa e
avisa quando sai uma versão nova (uma bolinha aparece perto do botão de
atualizar no widget). Clicar nela confirma a instalação e reinicia o app
sozinho — não é mais necessário voltar aqui pra baixar um instalador novo
a cada atualização, só nesta primeira instalação.

## Novidades recentes
- Botão de engrenagem (⚙) no card, visível só pro diretor — escolhe quais
  vendedores aparecem no gráfico "Vendas por Vendedor" e a cor de cada um,
  direto no widget, sem precisar pedir atualização.
- Ícone de conta conectada (mostra o usuário logado ao passar o mouse).
- Botão de logout, pra trocar de conta sem precisar editar arquivos.
- Atualização automática (ver acima).
