# Widget Gigalink — instalar no Mac

## Passo 1 — Baixar os arquivos
Acesse este link e baixe a pasta `mac` (botão "Code" → "Download ZIP", ou
peça pra alguém te mandar a pasta já baixada):

https://github.com/JoaoGigalink/widgets-gigalink-atualizacoes

## Passo 2 — Abrir o Claude Code
Abra o Claude Code no Mac, apontando para a pasta `mac` que você baixou.

## Passo 3 — Pedir pra instalar
Digite exatamente isto pro Claude Code:

> Segue as instruções do arquivo INSTRUCOES_CLAUDE_CODE_MAC.md e instala o
> widget pra mim.

Ele vai instalar tudo sozinho — pode levar alguns minutos.

## Passo 4 — Abrir o app pela primeira vez
O macOS vai mostrar um aviso do tipo:

> "Widgets Gigalink" não pode ser aberto porque o desenvolvedor não pôde
> ser verificado.

**Isso é normal** — não é erro, só acontece na primeira vez. Para liberar:

1. Clique com o botão **direito** (ou Control + clique) no ícone do app.
2. Clique em **Abrir**.
3. Confirme clicando em **Abrir** de novo na janela que aparece.

Depois disso, o app abre normalmente para sempre.

## Passo 5 — Fazer login
Na primeira abertura, o app pede usuário e senha. Use os que você já tem.
Se pedir pra trocar a senha, é normal — só seguir o passo.

## Pronto
O ícone da Gigalink vai aparecer em Applications, como qualquer outro
aplicativo. O widget abre sozinho toda vez que você ligar o Mac.
